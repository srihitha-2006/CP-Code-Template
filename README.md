# CP-Code-Template

A reusable Java template for Competitive Programming.

## Features

- Fast input using BufferedReader and StringTokenizer
- Fast output using PrintWriter
- Dedicated `solve()` method
- Ready for single or multiple test cases
- Easy to reuse for coding contests

## Project Structure

```
CP-Code-Template/
│
├── Main.java
└── README.md
```

## How to Use

1. Clone or download this repository.
2. Open `Main.java`.
3. Write your solution inside the `solve()` method.
4. Compile and run your program.

## Why this repository?

This template reduces the time spent writing boilerplate code during coding contests and helps maintain a consistent project structure.
